Access keys

Make a login for someone else. Pick what they may see, type their username, generate. They sign in on this page with that username and the key, and see only the ticked parts. Nothing is uploaded: the key itself carries the access, so no rebuild or deploy is needed.

Keys you made are listed only in this browser. To cancel a key, rotate the part it unlocks: python build.py --rotate "<name>" then python deploy.py. Every key that includes that part stops working; your own login is unaffected. New sessions added later are not in old keys: make a new key.
